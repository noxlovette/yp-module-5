## Поставленная задача

Взять broken-app, проверить его на:

1. Ошибки
2. UB
3. Performance

### В broken-app подготовлены:

- Минимум 5 разных дефектов (off-by-one, use-after-free/aliasing в unsafe, утечка, неверная логика, низкоэффективный алгоритм, гонка данных в модуле с потоками).
- Падающие тесты на часть багов и комментарии-метки для поиска остальных.
- Намеренно медленные функции с лишними аллокациями и плохой асимптотикой.
- Простые бенчмарки «до» (criterion или harness=false).
